# Internal Document AI Workbench

폐쇄망의 클라우디움 문서를 열어 편집하고, 사내 LLM으로 내용을 질의·요약·보완하는 문서 워크벤치.

현재 상태: **기획 초안 / 기술 검증 전**. 구현된 제품이 아니며, 아래 엔진과 연동 방식은 검증 대상이다.

## 목표

- 기존 폐쇄망에 구축된 클라우디움과 사내 LLM을 활용한다.
- PPTX·PDF를 하나의 사용자 화면에서 열람하고 형식별 편집 기능을 제공한다.
- 선택 영역 또는 문서 내용을 사내 LLM에 전달하고 수정안을 확인·적용한다.
- 유료 에디션·외부 클라우드에 의존하지 않는 공개 소스 기반으로 개발한다.
- 인터넷 환경에서 의존성을 준비하고 폐쇄망에서 설치·운영한다.

## 첫 개발 범위

ONLYOFFICE Community의 플러그인에서 선택 텍스트를 읽고, 내부 API를 거쳐 LLM 응답을 받은 후 사용자가 확인한 수정안을 원래 대상에 반영하는 흐름을 검증한다. 이후 클라우디움 저장 연동 및 Marker 분석을 단계적으로 추가한다.

## 공개 저장소 원칙

사내 문서, 내부 주소, 토큰, 인증서, 모델 가중치를 커밋하지 않는다. 예시는 합성 데이터와 가상 주소만 사용한다. 이 프로젝트 자체의 배포 라이선스는 아직 미정이며, 의존성은 각 라이선스를 따른다.
