# 선택 텍스트 질의·요약 QA

- 실행일: 2026-10-19 (Asia/Seoul)
- 대상: PoC 0.5.0, inspect 명령·계약·두 LLM 어댑터·화면
- 환경: Windows, 개발 Node 24.15.0, 배포 Node 24.22.0, 헤드리스 Chromium
- 입력: 합성 문장·모델·연결 코드만 사용. 실제 사내 문서·게이트웨이 미사용

## 자동 테스트

전체 55개 통과, 실패·건너뜀 0개. 기존 48개에 아래 7개 테스트를 추가했다.

- 편집 명령 2개: 여러 문단·run/빈 run의 읽기와 읽기 전용 표식, 적용 거부, 빈 내용·NUL·초과·문단 구분을 포함한 초과·지원하지 않는 요소 거부, 12,000자 경계. 쓰기 호출 0회 확인.
- 화면 핸들러 2개: 질문·요약 결과에는 적용 없음, 요약 기본 지시, 작업 전환 시 초기화·새 읽기 요구·기존 편집 복귀, 응답 작업 불일치 차단.
- API/어댑터 3개: 모의 답변의 명시적 표식과 proposedText 부재, 두 프로토콜의 실제 loopback HTTP 요청·자료 기반 프롬프트·여러 줄 응답·자격증명 비노출, 빈 답변·NUL·초과·잘린 응답 거부.

기존 다중 run·문단 수정 거부, 원문 충돌·삭제 검사, 편집 실패 복구 테스트는 그대로 통과했다.

## 헤드리스 브라우저

사용자 화면을 띄우지 않는 playwright-cli 세션에서 실제 app.js·서버·모의 편집기를 사용했다.

1. 두 문단의 합성 내용을 읽고 빈 요약 방향으로 요청. 문단 구분 유지, 모의 답변 표시, 원문 불변 및 적용 버튼 미표시 확인.
2. 질문 모드로 전환 시 대상 초기화. 합성 HTML·script 답변을 테스트용 응답으로 제공하고 실제 DOM에 img/script 노드가 생기지 않는 일반 텍스트 표시 확인. 원문 불변.
3. 수정 모드로 전환 후 여러 문단은 거부. 한 문단 수정안을 만든 뒤 원문을 바꾸면 적용 차단, 다시 읽고 요청하면 기존 수정 흐름 성공.
4. 브라우저 오류 0개. 합성 요약 화면의 배치와 표시를 스크린샷으로 확인. 세션과 임시 서버 종료.

[합성 화면](assets/read-only-summary.png), [CLI 재현 함수](assets/read-only-browser-flow.js).

재현 시 mock 서비스를 시작하고 `?demo=1`에서 로컬 연결 코드를 입력해 연결한다. 작업은 요약하기로 선택하고 `output/playwright` 폴더를 준비한다. 아래 CLI 함수는 이 초기 상태를 전제로 하며 시험용 응답을 가로채 HTML 표시 검사를 수행한다.

```sh
npx --yes --package @playwright/cli playwright-cli -s=readonly-qa open http://127.0.0.1:4318/?demo=1
# 화면 스냅샷의 연결 코드 입력·연결 확인·요약하기 선택을 완료한 뒤:
npx --yes --package @playwright/cli playwright-cli -s=readonly-qa run-code --filename docs/qa/assets/read-only-browser-flow.js
```

## API 근거와 한계

읽기는 기존에 조사한 [고정 SDK의 문단·run API](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/word/apiBuilder.js)를 순회한다. 새로운 쓰기 API는 사용하지 않는다. 모의 편집 API와 브라우저 데모는 실제 Desktop의 선택·문단·서식 구조를 대신하지 않는다.

실제 Desktop의 새 기능, 실제 사내 게이트웨이, 모델의 근거 준수·정확성·요약 품질은 미검증이다. 별도 VM/전용 테스트 PC는 아직 없으며 사용자 PC의 Office UI를 제어하지 않았다. 문서 전체·표·그룹·PDF 분석과 복잡한 텍스트 편집은 구현하지 않았다.

## 배포

Node 24.22.0을 포함한 Windows 배포물을 갱신했다. 별도 폴더에 풀고 시스템 PATH 없이 실행기 사전 점검 및 동봉 런타임의 전체 55개 테스트를 확인했다. 실제 폐쇄망 신규 설치 검증은 아니다.
