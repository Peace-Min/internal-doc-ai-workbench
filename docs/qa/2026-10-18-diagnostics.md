# LLM 연결 진단 CLI QA — 0.3.1

## 기획과 구현

사용자 PC 화면을 점유하지 않고 사내 게이트웨이 연결을 확인할 CLI를 제공한다. 기존 설정 로더와 어댑터를 재사용하며 합성 문장만 전송한다. 기본 mock 모드는 거부한다. 보고서는 코드·프로토콜·소요 시간·시도 여부와 HTTP 상태 코드만 포함한다. 응답 원문이나 자격증명은 기록하지 않는다.

## 검증 결과

- Windows, Node 22.14.0에서 `npm test`: 32개 통과, 실패 0.
- 추가 6개 테스트: 사전 설정 거부, 고정 입력/응답 비노출, 오류 분류, CLI 설정 오류 종료 코드, 두 프로토콜 실제 loopback HTTP, 인증/요청 timeout/본문 timeout.
- 합성 키·모델 식별자·주소·응답·서버 오류 문자열이 진단 JSON에 없음을 확인.
- 기존 플러그인 개체 적용·충돌 방지와 서비스 인증·CORS·응답 검증 테스트도 통과.
- `npm run package`: 플러그인·소스 ZIP·체크섬 생성 확인.

테스트는 모의 게이트웨이와 합성 데이터만 사용했다. 실제 사내 게이트웨이 요청, 사용자 데스크톱 제어, 실제 Desktop Editors UI QA는 수행하지 않았다. CLI의 OK는 프로토콜과 수정안 형식 확인이며 문장 품질이나 PPTX/PDF 통합 검증을 의미하지 않는다.
