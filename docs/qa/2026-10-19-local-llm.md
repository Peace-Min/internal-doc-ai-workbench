# 로컬 실제 추론 통합 QA — 0.10.0

## 작업 묶음과 환경

사용자 요청에 따라 미세한 기능별 보고 대신 로컬 실행 환경 준비 → 실제 모델 연동 → 브라우저 통합 흐름 → 자동 테스트·패키지 → Wiki를 한 단위로 진행했다.

- Windows, RAM 약 16GiB. UI 제어 없이 CPU 2스레드로 검증.
- 기존 llama.cpp b8201 (24d2ee052), 실행 파일 SHA-256: `9002798ec54546d0d7a298f6ac183dc7db9c930afe74ee61d1c53aa8c420bb20`.
- Qwen2.5 1.5B Q4_K_M, 986,048,512 bytes. 모델 blob SHA-256: `183715c435899236895da3869489cc30ac241476b4971a20285b1a462818a5b4`.
- 4,096 컨텍스트, max_tokens 512, 비스트리밍, loopback 전용. 모델과 시험 런타임은 저장소 밖 work/local-llm에 보관.
- Ollama 0.40.6 공식 ZIP SHA-256 `e359637575302f288d76c0007c408a4be9c7376d59c4f28684d63b232a44b427` 확인. 이 조합에서 GPU timeout 및 CPU 반복 출력·토큰 잘림 관찰. 응답 검사를 완화하지 않고 기존 llama.cpp 실행기로 전환. 원인 미확정.

## 실제 모델 결과

- 연결 진단 OK, 약 6.85초.
- 인증된 임시 Workbench 브리지 → 실제 모델: 질문 14.89초/62자, 요약 1.33초/22자, 문장 보완 0.71초/16자. 요청·종료 사유·응답 계약 통과.
- 질문에 합성 예산 950과 읽은 출처 2개 포함, 미확인 출처 0개. 요약은 예산을 포함했지만 출처 표기 0개. 출처 누락은 경고/검토 대상이며 프로토콜 성공과 품질을 구분한다.
- 단순 한국어 질문에서 중국어 혼합 관찰. 경량 모델의 언어·내용 품질은 인증하지 않는다.
- 헤드리스 Chromium → 실제 로컬 브리지 → 실제 모델: 질문·요약, 기록 2건, 당시 원문 대조, 읽기 전용 원문 불변, 실제 다운로드 이벤트, 문장 보완 결과의 모의 편집 적용 확인. 응답을 가로채거나 합성 응답으로 대체하지 않았다.
- 브라우저 재현: assets/local-model-browser-flow.js. 편집기는 모의이며 실제 PPTX 엔진 검증으로 표기하지 않는다.

## 자동 검증과 배포

`verify-local-llm` 명령을 추가했다. 설정 검증 후 고정 합성 자료만 보내며 답변 원문·인증값·주소·모델 식별자는 보고하지 않는다. 외부 주소·mock 거부, 임시 브리지 인증, 세 작업 경로, 출력 비노출을 자동 테스트로 확인했다. 전체 74개 통과. 실제 추론은 자동 테스트 기본 실행에 포함하지 않는다.

플러그인·소스·Windows ZIP과 체크섬 생성. Node 런타임·모델·추론 실행기 미포함. 사내 연결·실제 Desktop·완전 차단망 설치는 미검증이다. 시험 후 모델 서버·브리지·전용 헤드리스 브라우저를 종료하여 PC 자원을 반환했다. 시스템 설치·환경 변수 영구 변경·사내 설정 변경은 하지 않았다.
