# 실제 편집 검증 자료 준비와 실행 제한

2026-10-21 (Asia/Seoul). 기존 guest-prepared VM이 같은 ID로 실행 중임을 확인했다. 사용자 PC 화면을 점유하지 않는 실제 편집 검증을 시도했다.

## 완료한 작업

- 공식 고정 Desktop ZIP의 빈 PPTX를 이용한 생성기와 검사기를 추가했다. Python 3.11+ 표준 라이브러리만 사용하며 앱 런타임 요구에는 추가하지 않는다.
- 한 슬라이드·두 개체·세 문단·네 run의 합성 PPTX를 생성했다. 혼합 굵기·950/2026 숫자·경계 공백이 있다. Git에는 합성 문서만 포함하며 .pptx를 binary로 지정했다.
- 검사기로 패키지 부품 목록, 수정 대상 외 모든 바이트 유지, 개체·문단 수, 정확한 네 텍스트·공백, 굵기 조합을 확인했다. 기존 출력 경로 재사용은 거부하며 파일 SHA-256이 유지됐다.
- 기존 compare-pptx.ps1을 합성 XML 변경 사본으로 점검했다. 텍스트만 변경한 사본은 통과, 굵기를 의도적으로 손상한 사본은 거부, 동일 파일은 textChanged=false로 거부됐다. 이 사본들은 편집기 저장 결과가 아니다.
- 원본 fixture를 VM의 호스트 입력 폴더에 준비했다. 게스트에서는 C:\QAInput\page-edit-fixture.pptx로 접근할 수 있는 구성이다. 이번 작업에서는 편집기를 시작하지 않았다.

## 미실행과 이유

게스트 편집기 실행과 디버깅 연결 준비를 포함한 명령이 도구의 자동 승인 검토에서 거부됐다. 반환 사유는 blocked by policy뿐이며 더 구체적인 설명은 제공되지 않았다. 명령 전체가 실행 전에 거부됐으므로 편집기 시작·디버깅 포트 연결·문서 열기가 수행됐다고 간주하지 않는다. 같은 실행을 다른 방식으로 우회하지 않았다.

실제 페이지 읽기·적용·undo/redo·원문 충돌·숫자 보존·저장/재열기·시각적 서식 검증은 미실행이다. 호스트 앱·화면·입력 장치는 제어하지 않았다. [인수 검증 절차](../wiki/page-edit-acceptance.md)에 허용된 VM 제어 수단으로 재개할 순서와 필요한 증거를 기록했다.
