# 기록별 원문·출처 대조 QA — 0.9.0

## 기획 → 개발

구간별 분석을 검토하도록 기록 당시 원문을 패널 메모리에 보관하고 기록 번호별로 표시한다. 정형 출처를 당시 sources 목록과 비교하여 존재/미확인을 집계한다. 의미 검증·자동 통합·문서 쓰기는 추가하지 않는다. 보고서는 원문 사본 없이 대조 요약만 담는다.

## QA

- Node 22.14.0, 자동 테스트 72개 통과. 새 테스트 3개에서 출처 중복·범위 밖 번호·미인용·선택 개체·비정형 인용·기록 보존·잘못된 번호·삭제를 확인했다.
- 헤드리스 Chromium: 원문/답변 대조, 출처 경고, HTML 비실행, 재읽기 후 과거 사본 유지, 보고서 원문 미포함, 기록 삭제 확인. 재현: assets/review-browser-flow.js.
- `npm run package`: 플러그인·소스 ZIP·Windows ZIP·체크섬 생성. 이번 PC는 고정 배포 런타임이 없어 Node 런타임 미포함이다. 기존 0.8.0 동봉 런타임 검증과 구분한다.
- 실제 Desktop UI·사내 게이트웨이·실제 로컬 모델 추론 미실행. 사용자가 로컬 LLM 미설치라고 확인했다. 사용자 PC 화면을 제어하지 않았다.
