# 분석 기록·보고서 QA

- 실행일: 2026-10-19 (Asia/Seoul)
- 대상: PoC 0.8.0
- 환경: Windows, 개발 Node 24.15.0, 헤드리스 Chromium
- 합성 자료·응답만 사용. 사용자 데스크톱 앱·사내 문서·실제 게이트웨이 미사용

## 자동 테스트

전체 69개 통과, 실패·건너뜀 0개. 기존 65개에 분석 기록 테스트 4개를 추가했다.

1. 정상 질문·요약의 실제 지시·출처·제외 정보·모의 표식을 보관. 범위·작업 변경 후 앞선 기록 유지. 원본 본문과 연결 코드·주소가 보고서에 들어가지 않음. 삭제 후 보고서와 내보내기 상태 초기화.
2. 20건 뒤 추가 요청은 네트워크 전에 거부하며 앞선 기록을 보존. 지운 뒤 재요청 가능.
3. 응답 대기 중 삭제·내보내기 잠금. 대기 중 입력을 바꿔도 전송 당시 질문을 기록. HTML·줄바꿈은 일반 문자열로 보존.
4. 빈 답변·작업 불일치·네트워크 실패·취소 응답은 기록하지 않음. 다운로드 API가 없는 환경은 직접 복사를 안내하며 기록을 유지.

기존 편집·충돌·복구·범위 상한·두 LLM 프로토콜 테스트를 유지했다. 패키지 테스트에 보고서 스크립트 포함 및 HTML 로드 확인을 추가했다.

## 헤드리스 브라우저

합성 슬라이드 1~1과 2~2의 답변을 각각 기록하고, 범위·기본 요약 지시·출처·mock 표시를 대조했다. 작업을 수정 모드로 바꿔도 기록이 남았다. HTML 답변에서 script 요소가 생성되지 않았다.

실제 브라우저 다운로드 이벤트와 workbench-report.txt 저장을 확인했다. 파일 바이트의 UTF-8 BOM, 결과 2건, 두 범위, 모의 표시, HTML 일반 문자열, 연결 코드 미포함을 추가 검사했다. 내보내기는 모델 요청이나 기록 삭제를 일으키지 않았다. 기록이 있는 상태에서 새로고침하면 사라지며, 다시 요청해 생긴 기록을 지우면 내용과 기록 영역이 초기화된다.

브라우저 오류·경고 0개. [합성 화면](assets/report-history.png)을 확인하고 브라우저와 임시 로컬 서버를 종료했다. [CLI 재현 함수](assets/report-browser-flow.js)는 연결 완료한 mock 데모와 output/playwright 폴더를 전제로 실행한다.

```sh
npx --yes --package @playwright/cli playwright-cli -s=report-qa run-code --filename docs/qa/assets/report-browser-flow.js
```

## 배포 및 한계

공식 체크섬으로 검증한 Node 24.22.0 Windows x64를 포함해 배포물을 생성했다. 새 공백 포함 경로에 압축을 풀고 시스템 PATH를 비운 상태에서 실행기 사전 점검 및 동봉 런타임 전체 테스트 69개를 통과했다. 실행기 점검은 mock 설정만 확인하며 사내 요청을 보내지 않았다. 실제 Desktop의 다운로드 지원, 사내 모델·클라우디움, 인용 정확성, 차단 환경 신규 설치는 이 QA의 검증 범위가 아니다. 다운로드가 안 되는 환경에는 텍스트 직접 복사를 제공한다.
