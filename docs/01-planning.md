# 기획

## 사용자 의도

사용자는 클라우디움과 사내 LLM이 이미 구축된 폐쇄망에서 자체 문서 뷰어·에디터를 사용하려 한다. 문서 열람 중 AI를 활용하고 실제 편집 결과를 저장하는 것이 목표다. Marker를 문서 편집기 자체로 쓰려는 것은 아니다.

개발 워크플로우는 기획 → 개발 → QA → Wiki이며, 다른 PC·세션에서도 공개 Git 저장소를 통해 이어간다. 유료 제품 구매를 전제로 하지 않는다. 사용자는 개발 소스를 공개하고 라이선스 고지를 유지할 의향이 있다.

## 첫 PoC 합격 조건

합성 PPTX를 열고 본문을 선택하여 채팅 요청을 보내고, 수정안을 미리 본 뒤 원래 대상에 적용하며, 저장·재열기 후에도 내용이 유지되어야 한다. 채팅 도중 선택을 바꾸어도 엉뚱한 개체가 수정되지 않아야 한다.

## 편집 실패 복구 보강 (0.3.2)

변경 API가 실패를 반환하거나 예외를 던져도 원문 복구를 시도한다. 부분 쓰기 가능성을 고려해 결과 텍스트를 대조하며 복구를 확인할 수 없으면 성공으로 안내하지 않는다. 사용자에게 추가 편집·저장 전 확인 및 실행 취소/사본 복구를 안내한다. 실제 엔진의 트랜잭션 동작은 별도 환경에서 검증한다.

## 로컬 서비스 포트 설정 (0.3.3)

서비스의 WB_PORT 변경 시 플러그인 소스를 수정하거나 다시 패키징하지 않고 같은 포트를 입력하여 연결한다. 연결 주소는 127.0.0.1로 제한하고 포트는 1~65535 정수만 받는다. 포트나 연결 코드 변경 후에는 연결을 다시 확인한다.

## 실행·배포 묶음 (0.4.0)

Windows에서 런타임 포함 ZIP을 해제하고 실행기를 통해 서비스를 시작할 수 있게 한다. 설정 사전 점검은 서버·LLM 요청·연결 코드 파일 생성을 하지 않는다. 시작 실패가 기존 서비스의 연결 코드를 덮어쓰지 않아야 한다. 공개 소스와 원본 라이선스·출처·체크섬을 함께 제공한다. 편집기 설치 및 전체 차단 환경 실증은 별도 단계로 유지한다.

## 선택 텍스트 질의·요약 (0.5.0)

일반 텍스트 상자 하나의 여러 문단·run을 읽어 질문과 요약을 요청한다. 원문을 변경하지 않고 답변 전용 영역을 사용한다. 수정은 기존 단일 문단·단일 nonempty run 범위만 유지한다. 입력·답변은 각각 12,000자, 지시는 2,000자 이하이며 문서 전체·표·그룹·PDF 분석은 범위 밖이다. 모드 전환은 기존 대상·결과를 무효화한다. 읽은 시점의 자료라는 한계를 화면에 표시하고 실제 모델 품질은 별도 검증한다.

## 추가 확인 사항

0.7.0은 시작·끝 슬라이드를 지정하는 수동 구간 분석을 제공한다. 한 구간 상한은 200슬라이드·2,000개 개체·범위/출처 포함 12,000자다. 실제 범위 밖·역전·잘못된 번호는 읽기 전에 거부하며 원래 슬라이드 번호를 유지한다. 자동 분할·구간 통합은 범위 밖이다.

0.6.0 문서 읽기는 200슬라이드·2,000개 개체·출처 포함 12,000자까지 지원한다. 출처·제외 개체 수와 숨긴 내용 포함을 알리고, 초과·오류 시 부분 결과를 보내지 않는다. 이미지·표·그룹·노트·마스터는 제외하며 문서 수정에 연결하지 않는다. 긴 문서 분할과 인용 정확성은 후속 과제다.

두 LLM 프로토콜 모두 WB_LLM_MAX_TOKENS를 max_tokens로 전달한다(0.3.4). 기본값 2048, 허용 범위 1~8192 정수이며 잘린 응답은 수정안으로 사용하지 않는다. 실제 모델·게이트웨이의 필드 지원과 제한 준수는 실연결에서 확인해야 한다.

**PC 설치형 데스크톱 앱 우선으로 사용자 확정(2026-10-18).** 첫 PoC는 기존 ONLYOFFICE Desktop Editors에 설치하는 플러그인과 로컬 Node 서비스로 구성한다. 별도 통합 설치 프로그램은 다음 단계다.

운영 OS·하드웨어, 동시 사용자 수, 클라우디움 접근 API·버전 관리, LLM 인증·API 규격·이미지 지원·문맥 길이, PDF 편집 범위, 대표 문서의 폰트와 복잡한 개체 유형은 미확정이다.

## PoC 편집 범위 (0.2.0)

부분 문자열 대신 텍스트 상자 전체를 대상으로 한다. 한 문단·한 nonempty run의 일반 텍스트만 수정하고 다중 서식·그룹·표 등은 차단한다. 편집기가 남기는 빈 run은 보존하고 허용한다(0.2.0). 사용자 확인과 원문 일치 검사 후 원래 개체 ID를 찾아 수정한다. 실제 엔진의 기본 흐름 QA는 완료했고, 이 제한을 넘어선 편집은 추가 QA 후 확장한다.
