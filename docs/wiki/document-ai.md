# 문서 범위 질문·요약

## 사용

0.7.0부터 시작·끝 슬라이드를 지정해 긴 문서를 [구간별로 읽을 수 있다](slide-ranges.md). 아래 상한은 전체 문서가 아니라 한 번에 읽는 구간에 적용된다.

로컬 서비스를 실행하고 연결을 확인한다. 작업은 질문하기 또는 요약하기, 분석 범위는 ‘문서 일반 텍스트 · 읽기 전용’을 선택한다. 개체를 선택할 필요 없이 ‘문서 텍스트 읽기’를 누른다.

읽은 텍스트, 슬라이드·텍스트 개체 수, 제외·빈 개체 수를 확인한 뒤 요청한다. 본문에는 `[슬라이드 N · 개체 M]` 출처가 붙는다. M은 해당 슬라이드의 API 개체 순번이며 영구 ID가 아니다. 개체 순서는 시각적 읽기 순서와 다를 수 있다. 답변에 표시된 출처는 읽은 본문과 대조한다.

서비스는 내용을 읽기만 하고 요청 버튼을 누를 때 LLM으로 보낸다. 답변에 문서 적용 버튼을 제공하지 않는다. 내용이 바뀌면 다시 읽는다. 범위를 바꾸면 기존 캡처와 답변을 초기화한다. 문장 다듬기로 작업을 바꾸면 선택 개체 범위로 돌아가며 기존 편집 제한을 유지한다.

## 포함과 제외

숨긴 슬라이드·개체를 포함해 전체 슬라이드의 일반 텍스트 상자에서 읽을 수 있는 문단·run을 모은다. 이미지·표·그룹 내부·노트·마스터·레이아웃 텍스트를 별도로 추출하지 않는다. 텍스트가 아닌 문단 요소가 섞인 상자는 일부만 읽지 않고 상자 전체를 제외해 집계한다. 빈 상자는 별도 집계한다.

제외 개체 수는 슬라이드 API가 반환한 개체 기준이며 노트·마스터 내부 항목까지 센 값이 아니다. 일반 텍스트를 포함하지 않은 도형도 빈 개체에 집계될 수 있다. 지원 텍스트가 없으면 요청할 자료가 없다고 안내한다. API 오류·잘못된 문자열·NUL은 전체 읽기 오류로 처리한다. 읽은 것만으로 문서의 모든 의미나 정보를 분석했다고 간주하지 않는다.

## 상한

- 최대 200슬라이드.
- 슬라이드 API가 반환하는 개체 합계 최대 2,000개. 지원하지 않거나 빈 개체도 포함한다.
- 출처 표기·문단 구분·개체 구분을 포함한 총 텍스트 최대 12,000자.
- 기존 질문·지시 2,000자 및 답변 12,000자 제한은 유지한다.

초과 시 일부를 자르거나 먼저 읽은 부분만 보내지 않고 중단한다. 선택 개체 범위로 바꿔 분석할 수 있다. 긴 문서의 자동 분할·검색·통합 요약은 아직 구현하지 않았다.

## 답변의 출처

LLM에는 제공된 출처를 관련 사실 옆에 표시하고 없는 출처를 만들지 말라고 요청한다. 자동 인용 검증이나 모델 정확성 보장은 아니다. 문서 본문의 출처처럼 보이는 문자열도 신뢰할 수 없는 자료이므로 실제 답변과 원문을 대조해야 한다. 기본 mock은 실제 분석 결과를 만들지 않는다.

브라우저 데모는 본문 A/B를 각각 합성 슬라이드 1/2로 취급한다. [QA](../qa/2026-10-19-document.md)의 답변 화면은 시험용 합성 응답이며 실제 모델 결과가 아니다. 실제 Desktop·사내 모델·폐쇄망 연결 검증은 별도 환경에서 수행해야 한다.
