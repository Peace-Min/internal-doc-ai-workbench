# 분석 기록과 보고서 (0.9.0)

## 원문 근거 대조

답변이 추가되면 당시 읽은 원문과 답변을 대조 화면에 표시한다. 기록 번호를 입력하고 ‘기록 대조하기’를 눌러 앞선 결과도 확인한다. 이후 범위 변경·다시 읽기는 기존 기록의 원문 사본을 바꾸지 않는다. 현재 문서가 수정되었다면 대조 화면은 과거 읽은 시점의 내용이라는 점에 유의한다.

`[슬라이드 N · 개체 M]` 형태의 답변 출처를 중복 없이 세고 읽기 당시 sources 목록과 비교한다. 다른 범위의 번호나 존재하지 않는 번호는 ‘읽은 출처에 없음’으로 표시한다. 출처 없는 답변과 선택 개체는 별도로 안내한다. 다른 인용 형식은 자동 집계하지 않는다. 출처의 존재 여부만 확인하며 문장 의미·인용의 사실성·근거 충분성을 검증하지 않는다.

최대 20건의 원문 사본(건당 최대 12,000자)은 패널 메모리에만 추가 보관한다. 기록 지우기·패널 종료·새로고침으로 사라진다. 텍스트 보고서에는 원문 사본을 넣지 않고 출처 대조 요약·미확인 출처만 추가한다. 문서 개체를 이동·선택·수정하거나 추가 모델 요청을 보내지 않는다.

질문·요약의 정상 답변은 현재 패널의 분석 기록에 자동으로 추가된다. 슬라이드 범위·선택 개체·작업을 바꿔도 기록은 남는다. 문장 다듬기의 수정안, 실패·취소·검증 거부 응답은 기록하지 않는다.

## 사용 순서

1. 질문하기 또는 요약하기에서 범위를 읽고 요청한다. 긴 문서는 [구간별 읽기](slide-ranges.md)로 나눠 요청한다.
2. 분석 기록의 ‘보고서 내용 보기·직접 복사’에서 누적 결과를 확인한다.
3. ‘보고서 내려받기 (.txt)’로 UTF-8 텍스트 파일을 저장한다. 저장 후에도 기록은 남으므로 파일이 실제로 생겼는지 확인한다.
4. 파일 저장이 지원되지 않는 편집기에서는 보고서 내용을 선택해 직접 복사한다. 실제 Desktop의 다운로드 지원 여부는 별도 테스트 환경에서 확인해야 한다.
5. 최대 20건에 도달하면 추가 질문·요약을 중단한다. 먼저 내려받고 ‘기록 지우기’를 누르면 다시 요청할 수 있다. 기존 결과를 자동 삭제하거나 덮어쓰지 않는다. 수정안 기능은 이 한도와 무관하다.

## 보고서에 남는 내용

각 결과에는 질문/요약 작업, 실제 전송한 지시(빈 요약 입력의 기본 지시 포함), 읽은 대상·슬라이드 범위·출처 표기, 제외·빈 개체 안내, 읽기와 답변 시각(UTC), 모의 답변 여부, 검증을 통과한 답변을 담는다. 출처는 읽기 당시의 슬라이드·개체 번호이며 모델이 인용을 정확하게 했다는 인증이 아니다.

원본 문서 전체와 연결 코드·LLM 인증 설정은 보고서에 넣지 않는다. 다만 질문·답변에 문서 내용이 포함될 수 있으므로 내려받은 파일의 보관·공유 위치를 확인한다. HTML 형태의 답변도 화면과 파일에 일반 텍스트로 남긴다.

## 기록 수명과 한계

기록은 패널 메모리에만 있고 서버·브라우저 저장소에 자동 보관하지 않는다. 창 닫기·새로고침·플러그인 재시작 시 사라지므로 먼저 내려받는다. ‘기록 지우기’는 이미 내려받은 파일이나 현재 표시 중인 답변을 삭제하지 않는다.

문서 이름·파일 ID를 자동 구분하지 않으므로 다른 문서의 결과가 섞일 수 있다. 문서를 바꾸기 전에 내려받고 기록을 지운다. 구간별 답변을 시간순으로 모을 뿐, 전체 통합 요약·중복 제거·자동 분할·인용 검증·보고서 다시 불러오기는 제공하지 않는다. 실제 Desktop 저장 및 사내 모델 품질은 미검증이다.
