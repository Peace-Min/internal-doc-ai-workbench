# 긴 문서 구간별 읽기

## 사용

질문하기 또는 요약하기를 선택하고 분석 범위를 문서 일반 텍스트로 바꾼다. 시작·끝 슬라이드를 입력한 뒤 문서 텍스트 읽기를 누른다. 읽은 범위, 전체 문서 장수, 출처, 제외 개체 수와 전송할 텍스트를 확인한 뒤 요청한다.

- 시작을 비우면 1번부터 읽는다.
- 끝을 비우면 문서 마지막까지 읽는다.
- 둘 다 비우면 전체 문서다.
- 슬라이드 번호는 1 이상의 정수다. 시작이 끝보다 크거나 문서 밖이면 읽지 않는다.

예를 들어 300장 문서에서 시작 250, 끝 260을 입력하면 그 11장의 일반 텍스트만 읽는다. 출처는 원래의 250~260 번호를 유지한다. 일부 범위에는 `[분석 범위: 슬라이드 250~260 / 전체 300]` 머리말이 붙고 모델에도 같은 텍스트를 전달한다. 숨긴 슬라이드도 원래 번호에 포함된다.

범위 값을 바꾸는 즉시 이전 캡처와 답변을 초기화하므로 필요한 답변을 먼저 복사한다. 새 범위는 다시 읽어야 요청할 수 있다. 요청 중 범위 입력을 잠근다. 문장 다듬기는 선택 개체 범위에서만 제공한다.

## 한 번에 읽는 상한

각 구간은 최대 200슬라이드, 2,000개 API 개체, 범위·출처·문단 구분을 포함한 12,000자다. 문서 전체 장수는 200장을 넘어도 되지만 한 번에 읽을 구간은 이 상한을 지켜야 한다. 빈 개체와 제외 개체도 해당 구간의 개체 수에 포함한다. 선택 구간 밖의 슬라이드 개체는 탐색하지 않는다.

분량을 넘으면 자르지 않고 거부한다. 시작·끝 간격을 더 줄여 다시 읽는다. 한 슬라이드 또는 텍스트 상자 하나만으로 상한을 넘으면 현재 기능으로 그 내용을 자동 분할할 수 없다. 자동 구간 추천·분할·답변 통합·구간별 기록 저장은 구현하지 않았다.

이 기능은 사용자가 구간을 나누어 각각 질문·요약하는 방식이다. 구간별 결과만으로 문서 전체의 결론이 완성됐다고 간주하면 안 된다. 모델에는 표시된 범위만 근거로 답하도록 요청하지만 실제 모델의 정확성·출처 준수는 미검증이다.
