# 선택 텍스트 질의·요약

## 사용

1. 로컬 서비스를 실행하고 플러그인 또는 데모에서 연결을 확인한다.
2. 작업에서 ‘질문하기 · 읽기 전용’ 또는 ‘요약하기 · 읽기 전용’을 선택한다.
3. PPTX의 일반 텍스트 상자 테두리를 선택하고 ‘선택 개체 읽기’를 누른다. 읽은 내용을 화면에서 확인한다.
4. 질문 또는 요약 방향을 입력하고 요청한다. 요약 방향이 비어 있으면 핵심 사실과 조건 요약을 요청한다.
5. 답변의 근거와 내용을 원문과 대조한다. 답변에는 문서 적용 버튼이 없다.

기본 mock은 실제 분석을 흉내 낸 답을 만들지 않고 모의 답변임을 표시한다. 의미 있는 답변을 받으려면 [사내 LLM](internal-llm.md)을 설정해야 한다. 실제 사내 모델의 연결·정확성·문장 품질은 아직 검증하지 않았다.

## 범위와 제한

선택한 일반 텍스트 상자 한 개의 여러 문단·서식 구간을 일반 텍스트로 읽는다. 읽은 텍스트는 문단 구분을 포함해 최대 12,000자, 지시·질문은 2,000자, 답변은 12,000자다. 초과 시 잘라서 분석하지 않고 오류로 안내한다. 빈 텍스트·NUL·텍스트가 아닌 문단 요소는 거부한다.

표·그룹·이미지·PDF·문서 전체·다른 개체는 읽지 않는다. 하이퍼링크 등 별도 요소가 있는 문단도 현재 범위 밖이다. 내용의 전체 추출을 보장하지 않는 대체 경로로 조용히 건너뛰지 않는다. 읽은 시점의 내용을 요청에 사용하므로 문서가 바뀌면 다시 읽는다.

문장 다듬기로 작업을 바꾸면 기존 대상·답변·수정안을 초기화한다. 수정은 한 문단·한 nonempty run에 한정하고 원문 충돌 및 복구 검사를 유지한다. 복잡한 서식을 수정하려고 제한을 해제하지 않는다. 실제 Desktop의 새 읽기 범위 QA는 별도 VM/전용 테스트 PC 준비 후 수행한다.

## 답변과 원문

질의·요약 응답은 answer로 반환하며 replace_text의 proposedText와 구분한다. 화면은 요청한 작업과 응답 작업이 일치하는지 확인하고 답변은 일반 텍스트로 표시한다. HTML·스크립트·Markdown을 실행하거나 문서 변경 명령으로 바꾸지 않는다. 모델이 자료에 없는 내용을 확인할 수 없다고 답하도록 요청하지만 정확성을 보장하지는 않는다.

작업 선택은 요청 중 잠기며, 입력한 텍스트는 명시적으로 요청할 때만 LLM으로 보낸다. 로그·대화 기록 저장 기능은 추가하지 않았다. 답변은 현재 패널에 표시되고 패널을 닫으면 별도로 보관하지 않는다.
