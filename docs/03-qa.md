# QA 계획

## 실행 환경 원칙

사용자 요청(2026-10-18)에 따라 **사용자 PC의 화면·마우스·키보드를 점유하는 QA는 수행하지 않는다.**

- 기본: Node 단위/통합 테스트, 로컬 모의 HTTP 서버, 헤드리스 브라우저. 일반 테스트는 터미널 백그라운드에서 실행한다.
- 실제 Office UI: 별도 VM 또는 전용 테스트 PC에서 Desktop Editors를 실행해 검증한다. 사용자 PC에 창을 띄워 대신 검증하지 않는다.
- 자동화 실행 기록과 실패 화면·영상은 격리된 테스트 환경에서 수집한다. 공개 결과에는 합성 데이터만 포함한다.
- 모의 편집기와 헤드리스 UI 테스트는 실제 Desktop 엔진 통합 검증과 구분한다. 별도 환경 준비 전에는 미검증 항목을 그대로 유지한다.

## 결과 기록 양식

0.7.0은 [슬라이드 범위 QA](qa/2026-10-19-ranges.md)에 기록했다. 300장 문서의 후반 한 장, 범위 밖 미탐색, 머리말 포함 길이 경계, 입력 변경·요청 중 잠금·잘못된 범위 차단을 확인했다. 실제 Desktop 실행은 별도 검증한다.

0.6.0 문서 범위는 [문서 AI QA](qa/2026-10-19-document.md)에 기록했다. 출처·제외 수·총량 제한·범위 변경·부분 전송 차단을 확인했다. 실제 Desktop 실행과 모델 인용 정확성은 별도 검증한다.

0.5.0 선택 텍스트 질의·요약은 [읽기 전용 QA](qa/2026-10-19-read-only.md)에 기록했다. 자동 테스트와 헤드리스 브라우저에서 원문 변경 없음·모드 전환·안전한 답변 표시·기존 수정 흐름을 확인했다. 모의 편집기와 실제 Desktop 동작, 합성 응답과 실제 모델 품질은 구분한다.

0.4.0 실행·배포는 [배포물 QA](qa/2026-10-19-portable.md)에 기록했다. 새 폴더 압축 해제, 시스템 PATH 제거 상태의 동봉 런타임 실행, 중복 기동·연결 코드 보존·쓰기 실패 시 포트 반환·비밀 미포함·고지·체크섬을 확인했다. 인터넷 차단 PC의 새 설치 및 실제 편집기 UI 검증은 아니다.

0.3.4 출력 토큰 제한은 [토큰 제한 QA](qa/2026-10-19-token-limit.md)에 기록했다. 양쪽 프로토콜의 설정 전송과 잘린 응답 거부를 검증했으며 실제 사내 모델의 토큰 제한 준수 검증과는 구분한다.

0.3.3 서비스 포트 설정은 [포트 설정 QA](qa/2026-10-19-port.md)에 기록했다. 실제 화면 핸들러를 모의 DOM에서 실행하고 임의 loopback 포트의 서비스 연결·수정안 요청, 입력 검증과 재연결을 확인했다. 실제 브라우저 렌더링 및 Desktop 설치 UI 검증은 아니다.

0.3.2 편집 실패 복구는 [실패 주입 QA](qa/2026-10-19-recovery.md)에 기록했다. 삭제/삽입의 false 반환·예외·부분 쓰기·결과 불일치, 복구 실패를 모의 API로 검증한다. 실제 Desktop 트랜잭션·실행 취소는 별도 환경에서 추가 확인한다.

실행일 / 커밋 / 엔진·모델 버전 / 환경 / 합성 입력 / 실행 절차 / 기대 결과 / 실제 결과 / 통과 여부 / 증거 / 이슈를 기록한다. 증거에 사내 데이터가 있으면 비공개 보관하고 공개 문서에는 비식별 결과만 기록한다.
