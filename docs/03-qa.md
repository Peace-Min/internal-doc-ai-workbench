# QA 계획

아래는 제품 전체 QA 계획이다. PoC의 자동·모의 UI 검증은 [2026-10-18 결과](qa/2026-10-18-poc.md)에 기록했다. 실제 편집기·사내 시스템·폐쇄망 전체 QA는 아직 미실행이다.

| ID | 검증 | 기대 결과 |
| --- | --- | --- |
| Q01 | 합성 PPTX/PDF 열기 | 페이지·글꼴·표·이미지 표시 확인 |

| Q04 | 수정안 미리보기·적용 | 확인한 대상만 변경 |
| Q05 | 요청 중 선택/문서 버전 변경 | 잘못된 대상 적용 차단 |
| Q06 | 서식 보존·긴 문장 | 서식 손실·겹침·넘침을 확인 |

## 결과 기록 양식

실행일 / 커밋 / 엔진·모델 버전 / 환경 / 합성 입력 / 실행 절차 / 기대 결과 / 실제 결과 / 통과 여부 / 증거 / 이슈를 기록한다. 증거에 사내 데이터가 있으면 비공개 보관하고 공개 문서에는 비식별 결과만 기록한다.
